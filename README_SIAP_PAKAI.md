# ElectroLearn Lab 3D - Firebase Connected

Konfigurasi proyek Firebase sudah dimasukkan ke `index.html`.

## Wajib dilakukan sekali di Firebase Console
1. Buka proyek `electrolearn-lab`.
2. Pilih **Firestore Database**.
3. Klik **Create database**.
4. Pilih lokasi database.
5. Untuk uji coba tugas kuliah, pilih **Test mode** sementara.
6. Jalankan website melalui hosting atau server lokal, lalu coba login.

Koleksi yang digunakan aplikasi:
- `elearn_users`
- `elearn_scores`

Catatan: mode Test dapat dibuka oleh siapa saja dan hanya untuk percobaan. Sebelum dipakai sungguhan, ubah Firestore Rules dan gunakan Firebase Authentication.
