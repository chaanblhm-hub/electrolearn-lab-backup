PERUBAHAN LOGIN SISWA

Siswa sekarang dapat login dengan:
- Kolom Masuk sebagai: Akun Siswa
- Username atau nama lengkap: ketik nama lengkap siswa sendiri
- Password: siswa123

Contoh:
Nama: Rezha Nabilah Mumtazah
Password: siswa123

Jika nama tersebut belum terdaftar, akun siswa akan dibuat otomatis di browser.
Sinkronisasi lintas perangkat tetap memerlukan database online/Firebase yang telah dikonfigurasi.
